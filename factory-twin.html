Factory Twin

A digital twin of the software factory. It composes machine-readable sources — maintenance systems, the capability registry, plant work orders, the funnel graph — into one deterministic semantic snapshot, so the whole build pipeline can be observed in one place. It never mints authority: observability only.

What it tracks

  • Machines — build cells, fixtures, adapters, subsystems, each with lifecycle and health (healthy-verified, candidate, degraded, quarantined).
  • Work orders — every job moving through stations: intake, planning, work-cells, QC, rework, release. Receipts travel with them.
  • Routes — how machines and funnel stages connect.
  • Authority versions — which funnel law is production, which is candidate.

Honest limits

The twin is a data layer. The 3D factory floor — walking the stations, seeing the work — is not built yet. The blueprint forbids faking it: no animated busy-work, no health derived from rendering. When the physicalization lands, it shows this data and nothing else.
