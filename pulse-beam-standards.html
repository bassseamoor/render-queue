Pulse Beam

Design Law v1

One environment. No capability loss.

Beam standardizes material, hierarchy, touch, focus, motion and migration without pretending a global stylesheet is the same thing as a real component redesign.

Non-negotiable laws

1
Function before chrome

Visual migration may not remove controls, inputs, states, routes, storage or outputs.

2
Sparse primary view

Complexity reveals contextually through Library, Inspector or a component's own workspace.

3
44px touch floor

Touch surfaces remain operable without precision tapping.

4
No accidental horizontal overflow

Mobile width is respected unless overflow is core to the component's function.

5
State is not color alone

Emerald means verified/live/success, but text/shape/state remains legible independently.

6
Reduced motion is first-class

Spatial travel and ambient animation collapse gracefully.

Migration ladder

Legacy compatibleWorks inside Beam. Compatibility tokens/touch/focus normalization applied. Not called redesigned.
Beam auditedNo-loss behavior inventory captured. Mobile/touch/parity checks pass.
Beam nativeIntentional bespoke redesign to Beam law with behavior parity evidence.

A component cannot become Beam-native merely because Beam CSS was injected into it.
