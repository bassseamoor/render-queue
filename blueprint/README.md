# MOOR whole-product blueprint

`moor-blueprint.html` is a self-contained editor. It opens independently, uses no remote library, and exports a complete editable version. Pulse mounts the same file from Bin and registers it as a Funnel project.

The baseline covers 30 inspected sources, the union of 96 catalog entries and 70 tool records, all 20 atoms and 20 kits, eleven detailed app contracts, available experiments, eight studios, historical directions and failure records. The complete repository file inventory distinguishes features from supporting assets. Physical PC and phone behavior was not verified. Product naming and free/paid boundaries remain explicit owner decisions.

Build order follows only prerequisite edges. Other relationships do not fabricate order. Removing a card preserves a tombstone, bridges compatible build connections and flags replacement obligations; incompatible contracts stay unresolved. Changes are transactional and reversible. Expanding cards triggers bounded geometry measurement, preserving visible connections.

Generated reference code demonstrates a mechanism rather than the full production feature. Imported HTML executes in an opaque-origin iframe with external connections blocked. Structured `moor.reference-ui` JSON renders inputs, buttons, state, lists, cards and charts. Runtime errors are reported by the preview. References remain exact text through save/export/import.

Run `node blueprint/build.cjs` to rebuild after source/data changes. Run `node tests/blueprint-checks.cjs` and `node tests/pulse-checks.cjs` before release. Keep the independent registration, Funnel seed and manifest entry together. Never merge older dashboard snapshots over concurrent work.

The proposed sequence is contracts → deterministic operations → local persistence/recovery → permissions/runtime → registry/shell → one proven save-and-return app → creation/verification → optional continuity, sharing, distribution and commerce. The complete map preserves later worlds/games and history without turning them into present production promises.
