SELL // WHY THIS EXISTS

Links were leaking out of the platform.

Every standalone link opened a bare file — no Pulse, no catalog, no ecosystem. Retention died one tab at a time.

✕ Before

Tap a link → a file floats alone in the browser. The user is outside the OS. Nothing around them. They leave.

✓ After

Tap a link → Pulse opens with the thing mounted inside it. The user lands in the ecosystem, surrounded by everything else. Every link is a door in.

Components evolve. A file is a snapshot — Pulse is where the living version lives.
Deep links mean no one ever sees a stale copy again.

Execute to the nail.

Write the URL on open

hook → openComponent(id)

Values — every one calculated
ValueWhy this, exactly
replaceStateNot pushState — writing the URL must not spam the back button. One entry per view, always.
encodeURIComponent(id)Component ids are strings; encoding makes exotic ids URL-safe instead of silently breaking.
?tool=Single param, human-readable, grep-able. The whole contract is one key.
try/catchhistory is unavailable in some sandboxed/file contexts — the dashboard must never throw on URL bookkeeping.

3

Read the URL on boot

hook → after Smart.init + render()
Anchor — exact, unique in file
if(window.Smart) Smart.init(COMPS); render();
try{ var _dlTool=new URLSearchParams(location.search).get('tool');
  if(_dlTool && find(_dlTool)) openComponent(_dlTool); }catch(e){}
if(window.Smart) Smart.onReady(function(){ ... });
Values — every one calculated
ValueWhy this, exactly
After render()The stage exists before the deep link fires — openComponent needs rendered DOM, not just data.
URLSearchParamsNo hand-rolled regex query parsing. The platform API handles encoding edge cases.
find(_dlTool)The id is validated against the live registry before opening. An invalid id can never break boot — it is ignored silently.
Param beats storageAn explicit URL overrides the restored localStorage focus. Stated intent outranks remembered state.

Turtles: find() is the dashboard's own lookup — no new validation logic. openComponent() is the existing open path — no new mount logic. The feature adds zero new mechanisms; it only wires the URL to machinery that already exists.

DATA // THE CONTRACT

The param is the data.

The infrastructure exists. What this feature adds is data — one parameter contract:

DatumValue
Parameter?tool=<id>
id domainAny registered COMPS id — factorytwin, blueprintstd, blueprintsop, blueprintdl, concierge…
Invalid idIgnored silently. Dashboard boots normally. A bad link never breaks the platform.
EmptyBare dashboard. Existing localStorage restore behavior untouched.
