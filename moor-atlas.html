Smart routes use the terrain to avoid water and grades above 70%. They are sampled every 5 m and are planning estimates. Route playback is a preview marker, not live player movement.

Composition: Glass Map provides the optional micro-relief field; Grid Coords provides the original 0.5 m coordinate codec; HoloPanel displays the inspector; Moor Beta provides the terrain, world shape, and 3D map. Camera panning, top view, tools, and routing are Atlas extensions.

Limits: This is one local 400 m sector. Coordinate codes have no world identifier; pair them with the seed or exported world. The original codec’s checksum has known gaps for some character substitutions. Claims are local annotations. No live multiplayer, server ownership, collision routing, or cross-world travel.

Reuse: Export contains the world and component wiring. Import accepts Atlas and Moor Beta world documents. The standalone download needs no internet. window.MoorAtlas exposes getWorld, setWorld, sample, selectPoint, and planRoute; events use moor-atlas:change and moor-atlas:select.
